# Easyian website (Django · MVT)

Claymorphism website for **Easyian Tech OPC Private Limited** — Home, Services (+ a page per service),
DialSathi, About & Contact, and a full Blog — with almost every piece of content editable from the
Django admin, SEO built in, and a lead form protected by an invisible (hidden) captcha.

## Run it on Windows

```powershell
cd C:\Users\shiwansh\easyian
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
python manage.py migrate
python manage.py seed_site          # starter content from the design
python manage.py createsuperuser
python manage.py runserver
```

Open http://127.0.0.1:8000 for the site and http://127.0.0.1:8000/admin/ for the admin.
(`gunicorn` in requirements is for Linux servers. On Windows you can skip it, or ignore the install error.)

Run the tests with `python manage.py test`.

## Hidden captcha on the lead form

Visitors never see a puzzle. Each submission must pass all of these checks (`leads/antispam.py`):

1. **Honeypots**: two fields that people can't see. Bots fill them and get a fake "success" reply.
2. **Signed time trap**: a form sent within 3 seconds of loading, or after being open for hours, is rejected.
3. **Proof of work**: after the visitor first types, taps or focuses the form, the browser solves a small SHA-256 puzzle in the background. Scripts that just POST the form fail.
4. **One-time challenge**: each form token works once, so captured posts can't be replayed.
5. **Rate limit**: 5 submissions per IP per hour (configurable).
6. **Link filter**: messages stuffed with links are rejected.
7. **Optional Cloudflare Turnstile** (invisible): set `TURNSTILE_SITE_KEY` and `TURNSTILE_SECRET_KEY` in `.env`.

## SEO built in

- A unique `<title>`, meta description, canonical URL and robots tag on every page, all editable
- Open Graph and Twitter cards, with a default 1200×630 share image (generated by `seed_site`)
- JSON-LD structured data: Organization, WebSite, BreadcrumbList, Service, SoftwareApplication with INR offers, BlogPosting and FAQPage
- `/sitemap.xml` (pages, services, posts, categories) and `/robots.txt`
- `/blog/feed/` RSS feed
- Clean slugs, a single `<h1>` per page, semantic HTML, lazy-loaded images, and `noindex` on search results and tag archives
- Mobile-first, accessible design: keyboard tabs, skip link, focus rings, `prefers-reduced-motion`

## Going live (summary)

1. Set `DJANGO_DEBUG=False`, `DJANGO_SECRET_KEY`, `DJANGO_ALLOWED_HOSTS`, `DJANGO_CSRF_TRUSTED_ORIGINS`
   and `SITE_URL=https://your-domain` in `.env`.
2. `python manage.py collectstatic`, then serve `staticfiles/` and `media/` from Nginx.
3. Run with `gunicorn config.wsgi:application` behind Nginx over HTTPS.
4. Submit `https://your-domain/sitemap.xml` in Google Search Console.
